# 0.2.1 Starter

This document tracks the first accepted hardening starter for the upcoming
LinuxDesktop2026 `0.2.1` version. It is not the full release scope.

## Accepted Hardening Starter

### Add Linux LeakSanitizer Release Evidence

Review finding:

- The current ASan/UBSan sanitizer lanes deliberately disable leak detection
  with `ASAN_OPTIONS=detect_leaks=0` and `LSAN_OPTIONS=detect_leaks=0`.
- For a library with C ownership boundaries and threaded watcher lifetime
  logic, at least one Linux leak-detection configuration should be part of
  routine release evidence.

Decision:

- Keep the existing GCC and Clang ASan/UBSan lanes unchanged so their signal
  remains comparable.
- Add a separate blocking Ubuntu/Clang LeakSanitizer lane.
- Mirror the regular sanitizer build shape: tests enabled, examples enabled,
  and watcher test hooks enabled.
- Run the full CTest suite.
- Use ASan leak detection explicitly through
  `ASAN_OPTIONS=detect_leaks=1:halt_on_error=1` and
  `LSAN_OPTIONS=detect_leaks=1`.
- Do not add LSan suppressions unless an observed third-party or runtime leak
  proves one is necessary.

Acceptance evidence:

- `.github/workflows/ci.yml` contains a dedicated `Linux LeakSanitizer` job.
- The job configures with Clang on Ubuntu, builds the project, and runs CTest
  with leak detection enabled.
- Local verification should attempt the equivalent configure, build, and CTest
  flow before treating the change as ready.
