# 0.2.1 Starter

Work has started on the upcoming LinuxDesktop2026 `0.2.1` version. This file is
only the release-line marker; the compact hardening backlog lives in
`.scratch/review-hardening/ORDER.md`.

## Initial Hardening Threads

- Current `0.2.1` release-gate status is listed in
  `.scratch/review-hardening/ORDER.md`; there are no active blockers.
- The first accepted CI hardening change added a dedicated Linux LeakSanitizer
  lane with Clang and explicit leak detection.
- The first non-blocking `ld_watch` hardening candidates came from the
  September 7, 2026 external scan of Nextcloud Desktop watcher overload
  behavior.
- The Nextcloud-shaped FlavorTest probe is now present as synthetic evidence
  only; it does not claim that LinuxDesktop2026 fixes Nextcloud Desktop issue
  `#7873`.
- The large-tree watcher-noise probe now records raw notifications,
  coalesced candidate paths, settled-file pending work, validation-call counts,
  and deliberate queue-saturation overflow at CI-safe scale, with opt-in local
  scale for larger runs.
- The Nextcloud-shaped diagnostic decision is product-boundary-owned for
  `0.2.1`: `ld_watch` keeps overflow and bounded delivery signals, while the
  FlavorTest adapter summarizes candidate coalescing, dropped candidates,
  validation calls, and user-facing log lines without adding public watcher
  counters.

## Non-Blocking Watcher Candidates
