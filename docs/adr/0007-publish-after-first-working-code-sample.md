# Publish after the first working code sample

Status: accepted; initial condition satisfied by the working `ld_settings`
sample.

The project should become public once it has at least one tiny working code sample, supported by the survey and design documents. This gives GitHub users and AI agents something executable to inspect instead of launching with documentation alone.

This ADR is now historical guidance rather than current project status. The
current public README should describe module maturity and validation evidence,
not imply that publication is still waiting on the first executable sample.
